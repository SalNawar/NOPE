## How it was decided

- Every finding was checked in the code, not only by its commits: six reviewers read the 164 findings at main `d8d46a4` (the commits naming each id from `git log --all --grep`, the phases' as-built notes, then the code the claim names); the 39 whose files main changed afterwards (phase 16 part 2, phase 23 part 1) were read again at `f9b6c79`; this track's own fixes are named by commit.
- **DONE**: fixed in today's code (the commit is named; "here" = this branch). **MAPPED**: a phase still running takes it (9 labourers, 23 balance). **OBSOLETE**: the code it names is gone or rewritten. **DEFERRED**: its fix needs a file a running track edits, the art side, the asmdef split (the overhaul's own slice), or a decision of Saleh's (behaviour-changing); the reason is given. **OPEN**: still there, low, not taken in this run.
- A finding fixed in part is filed under what its remainder needs (e.g. DEFERRED with "here … (in part)").
- Files kept out of this track: the running tracks' own edits (phase 9 `redesign/p09-labourers`, the fix branch `fix/hall-frame-and-glyphs`, phase 23 `redesign/p23-balance`, `epic/pass-1`: their commits beyond main plus their worktrees' uncommitted edits; at the start, while main was `d8d46a4`, the wider `git diff d8d46a4 origin/<branch>` lists, phase 16 part 2 included), `Assets/Scenes/*.unity`, `world_source.json`, `ContentSheetMap.cs`, the builder's App/Panes/Keys partials, and `docs/FEATURES.md` (phase 9 edits it). `RunManager.cs` and `HomeManager.cs` stay out while phase 23 runs.
