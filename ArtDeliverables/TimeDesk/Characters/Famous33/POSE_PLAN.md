# Full-body poses

User requested poses in addition to four expressions. Each traveller receives three additional whole-figure sprites: explaining (one palm-up hand), thinking (one hand at chin), objecting (one open palm outward). These are coherent full character redraws with connected shoulders and arms, not detached animated hands. Feet, body scale and head location stay aligned with neutral. Identity, period clothing and accessories remain consistent. Expressions retain the neutral body pose for runtime facial substitution.

Total target: 33 x (4 expressions + 3 poses) = 231 original 1024 x 1536 green-background images. Each asset is recorded only after saving and checked visually before being marked reviewed. Raw originals still require the existing keying/registration pipeline before Unity use.
