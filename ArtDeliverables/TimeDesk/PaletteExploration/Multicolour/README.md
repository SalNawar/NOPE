# Multicolour revision — 2026-09-25

Supersedes the first concept boards after Saleh rejected their single-hue appearance. These schemes use contrasting material zones with neutral lighting; each scene deliberately mixes warm and cool hues. No game assets were recoloured.

The exact source values are in palettes.json. Image-generated labels are illustrative and may contain transcription differences.

Roles in swatch order:
1. hall walls and floor
2. structural columns and boards
3. desk surface
4. CRT casing and keyboard
5. phone and lamp
6. metal trim
7. UI and portal accent

Papers use off-white and linework deep charcoal. Material colour is separate from time-of-day grading.
