Critical colour assignments:

Lamp is original banker's lamp with charcoal shade/base and small muted brass supports. PC, mouse, stapler neutral porcelain white, no beige and no blue cast. Keyboard predominantly neutral porcelain/graphite with just a few lavender/apricot function keys, NO large blue key groups. NEXT housing graphite with porcelain frame and white letters. No new characters. No repair grid. Smooth walnut tabletop with broad gentle value changes, no dense grain or photographic texture.
Lighting: clear comfortable daytime, neutral daylight, soft cel shadows, clean flat colour shapes; neither gloomy nor photoreal. Preserve actual screenshot composition exactly. Return ONLY the recoloured full game screen, no swatches, no border, no caption, no palette labels.
