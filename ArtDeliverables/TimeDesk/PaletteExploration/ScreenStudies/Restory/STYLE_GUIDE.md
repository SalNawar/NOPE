# ReStory-based screen direction — 2026-09-25

Latest single palette study, using Saleh's full ReStory desk screenshot and the original game view. It supersedes the abstract charts, monochrome boards, generic beige schemes and overly realistic mockups. This PNG is an AI paint-over, not a runtime capture. The lamp shape drifted toward the reference; treat its finish as guidance, not an approved model replacement. The teleporter's decorative bronze segments in the paint-over are not a requested palette change; retain a coherent neutral-metal ring in implementation.

Art direction:

- Quiet, smooth dark warm-brown desktop with broad boards, soft tone variation and almost no visible grain at game-view scale. Remove the busy high-contrast tabletop grain.
- Clear medium blue plain OFFICE pad; no repair cutting grid.
- Cool pale-grey/off-white CRT rather than yellowed beige.
- Distinct plausible object finishes: burgundy till, softer coral phone, dusty-blue tray, tan card/ink holder, mustard pen cup, charcoal lamp, navy NEXT base.
- Controls have functional colour groupings: pale keyboard keys with a few blue/orange accents; charcoal calculator number keys plus pale and amber function groups.
- No green/teal/olive: walls, separators, pads, lamp, till, NEXT, keyboard, flags, portal and other props.
- Natural building colours vary independently. Glass retains transmission and simple reflections. Preserve original floor and geometry.
- Four background flags are actual 2D SpriteRenderers in Unity. Their cloth artwork uses ochre; supports stay 3D.
